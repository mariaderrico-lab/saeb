Como abrir o projeto

1. Abra o XAMPP e clique em  Start no Apache e no MySQL.
2. Copie a pasta `SAEPVision` para `C:\xampp\htdocs\`.
3. Acesse `http://localhost/phpmyadmin`, clique em Importar, escolha o arquivo `database/saepvision.sql` e clique em Importar.
4. Abra no navegador: `http://localhost/SAEPVision/`
